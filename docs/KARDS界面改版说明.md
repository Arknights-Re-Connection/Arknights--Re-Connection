# 再连接 · KARDS 视觉参考改版

版本：v0.2.0。日期：2026-10-03。

## 参考与适用边界

作者要求参考 [KARDS 牌桌导览](https://www.kardsplayer.com/zh/how-to-play)，附图中明确希望界面参照 KARDS、看起来更舒适。已实际打开参考页面并查看牌桌：主要借鉴木质桌面、纸质卡框、费用角标、攻防标记、上下两端手牌和实体卡片层叠感。

本次修改视觉与信息呈现。游戏仍使用原手稿的 9×9 地图、双方各八个部署格、固定目标点与三次有效抵达胜利；资源增长、行动次数、伤害、反击、技能与状态等继续由原规则引擎裁定。没有引入参考游戏的阵线、总部生命、抽牌或疲劳规则。

## 已实现

| 区域 | 改版 |
| --- | --- |
| 主菜单 | 行动档案纸张、部署规划图、三张实体卡片陈列，保留正式对局、演练、牌组配置及继续入口 |
| 整体 | 深色木质桌面、暖灰纸张、橄榄绿与黄铜色，减少发光线框 |
| 棋盘 | 有坐标与等高线纹理的作战图，部署格、目标点和动作高亮仍明确区分 |
| 地图单位 | 小型纸质干员卡，实时显示生命与攻击/治疗数值，保留朝向、选择高亮和状态标签 |
| 手牌 | 扇形排列、叠放阴影、悬停/选中抬起；费用角标、名称、攻击/治疗量与生命独立显示 |
| 费用 | 当前具备基础使用条件的卡牌费用显示黄色；费用不足或部署次数用尽等情况显示灰色，仍可选牌查看详情 |
| 卡面 | 原创代码生成的矢量插画；八职业以装备、色调区分，烟雾、寒冷与灼燃等指令有对应图案 |
| 上下牌区 | 保留手稿顺序：敌方指挥点、抽牌堆、背面手牌、弃牌堆；我方指挥点、弃牌堆、手牌、抽牌堆 |
| 左侧 | 保留朝上敌方、朝下己方的回合三角，以及三次抵达进度 |
| 右侧 | 纸质干员档案、状态、技能和可用操作；结束回合按钮固定在档案底部 |
| 确认/存档/组牌 | 统一纸质档案与军绿色控件，继续使用同一套规则校验和存档 |

卡牌费用颜色表示基础资源和次数是否满足。目标、范围、容量与其他状态仍在结算预览中进一步校验，不能把黄色角标解释为对任意目标都可使用。

## 文件与资产

- `apps/client/src/kards-theme.css`：牌桌、卡牌、档案和各分辨率布局。
- `apps/client/src/OperatorArt.tsx`：原创矢量卡面。
- `apps/client/src/Board.tsx`：纸质地图和单位卡显示。
- `apps/client/public/textures/wood.svg`、`paper.svg`：原创本地纹理；生产构建后位于 `dist/textures`。
- `apps/client/src/App.tsx`：菜单、卡牌费用/攻防、扇形排列和回合按钮呈现。

以上纹理和插画均随应用本地加载，未将参考网站图片作为运行资产。`packages/rules` 与 `packages/content` 的玩法和卡牌数据未因这次界面调整改动。

## 验证

35 项现有规则测试与 13 组浏览器流程通过；TypeScript 检查和生产构建通过。浏览器流程覆盖菜单、组牌、部署、攻击/反击、技能、治疗、状态、撤退、视角交接、存档、超限弃牌和终局。

已在 1280×720、1440×1000、1920×1080 下检查完整手牌区可见且无横向溢出，并通过生产构建中的实际拖拽部署检查。
