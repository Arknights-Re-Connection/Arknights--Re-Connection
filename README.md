# 明日方舟 — 再连接 · 可玩雏形

按[游戏规则 PRD](./明日方舟再连接_PRD.md)与[技术架构 PRD](./明日方舟再连接_技术架构PRD_管理层评审版.md)制作的本机双人卡牌战棋原型。开发版本为 `0.2.0`，界面采用参考 KARDS 的实体战术牌桌风格；改版说明见[界面改版说明](./docs/KARDS界面改版说明.md)。

## 运行

已安装依赖的本机直接双击 **启动雏形.cmd**，再访问 **http://127.0.0.1:5173/**。运行窗口需要保持打开。

首次在其他电脑运行，需要 Node.js 24 LTS，然后在本目录执行：

```powershell
npm.cmd ci
npm.cmd run dev
```

## 试玩顺序

1. 点击「进入战术演练」。演练从预置战场、24 指挥点与已充能干员开始，便于立即体验战斗；它不是正式规则开局。
2. 选择下方手牌，点击高亮部署格，选择朝向并确认。也可以把手牌拖向地图。
3. 点击地图干员，在右侧选择移动、攻击、治疗、技能或撤退。指令卡选中后再选择地图目标。
4. 攻击、移动、部署前会显示规则校验和结算预览。非法操作无法确认；右键或 Esc 取消。
5. 点击「结束回合」，把电脑交给另一位玩家，由接手玩家确认后显示其手牌并旋转地图。
6. 「对局存档」可手动保存、继续、导出与导入 JSON。每个回合起点自动保存；若在回合中操作后离开，先手动保存。
7. 要验证正式开局，回到主菜单点「开始本机对局」。双方使用当前配置的同一测试构筑，各自独立洗牌。

## 当前内容

- 9×9 地图、双方目标与部署区域、左侧朝上/朝下回合标识，以及手稿指定顺序的上下牌区。
- 30 张构筑；20 种干员覆盖八职业，8 种指令，共 28 种**原创测试卡定义**。卡池用于验证机制，数值未经过平衡测试。
- 部署次数、职业移动费用、朝向范围、同格阻挡与队列、主动攻击及单次反击、自动交战、医疗、普通/弹药技能。
- 卡实例费用增长与弃牌回收、永久移除得分、三人抵达胜利及 40 全局回合结算。
- 烟雾、寒冷/冻结、三类元素累计与损伤。灼燃保留作者确认的「再次爆发为 3」；免疫期内每次灼燃元素伤害仍为 1。
- 手牌超限选择弃牌、测试牌组编辑、IndexedDB 存档、JSON 导入导出及公开作战日志。

## 本版边界

当前为浏览器里的**本机双人轮流对战**。界面已增加木质牌桌、纸质卡框、原创矢量插画、费用角标、攻防数字及扇形手牌。尚未实现 AI 对手、联网房间、桌面安装包、声音与正式卡池美术。测试卡池不包含反击型指令、特殊连击与额外入场等后续卡面机制；反击型指令的异步响应窗口也未实现。

原型采纳了规则 PRD 中标注的补全规则用于试玩；这些标记不代表作者另行确认。新部署重建生命、状态与充能，弃牌中的实例费用保留。

换人遮屏是本机操作保护。完整对局状态仍在本地浏览器和私有存档中，导出的 JSON 包含双方手牌。联网版本需由权威服务器维护隐藏信息与判定。

## 工程与验证

| 目录 | 职责 |
| --- | --- |
| `packages/rules` | 纯 TypeScript 规则引擎、动作、状态校验与玩家视图 |
| `packages/content` | JSON 测试卡池与牌组校验 |
| `apps/client` | React 操作界面、Phaser 棋盘、IndexedDB 存档 |
| `scripts/browser-smoke.mjs` | 真实浏览器操作验收 |
| `artifacts` | 验收截图和测试存档，默认不纳入版本控制 |

```powershell
npm.cmd test
npm.cmd run build
# 浏览器验收要求上述开发服务运行中；首次安装验收浏览器：
npx.cmd playwright install chromium
npm.cmd run test:browser
```

构建结果位于 `dist`；可通过 `npm.cmd run preview` 在 http://127.0.0.1:4173/ 预览。规则引擎只接受标准动作，界面预览与实际提交均调用同一引擎，棋盘不维护另一套可写对局状态。

本次实测范围见[雏形验收记录](./docs/雏形验收记录.md)。
